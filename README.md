# AI Task Management System

## Version
v1 - Local Node.js Application

## Objective
Learning infrastructure engineering through evolving a real-world application.

## Tech Stack
- Node.js
- Express

## Current Features

- Health check endpoint
- Create task
- Get all tasks
- Get single task
- Update task
- Delete task

---

## Current Architecture

- Routes layer
- Controllers layer

---

## API Endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | /health | Health check |
| GET | /api/tasks | Get all tasks |
| GET | /api/tasks/:id | Get task by ID |
| POST | /api/tasks | Create task |
| PUT | /api/tasks/:id | Update task |
| DELETE | /api/tasks/:id | Delete task |
